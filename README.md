## 📖 项目简介

本项目是一个基于《洛克王国》世界观的 **18 种属性克制与抵抗关系计算器**。程序使用 Python 编写，内置了游戏内全部 18 种属性（普通、草、火、水、光、地、冰、龙、电、毒、虫、武、翼、萌、幽、恶、机械、幻）的复杂交互逻辑，可精准计算任意属性组合在战斗中的攻防克制链。

## ✨ 功能特点

### 🔍 多维关系查询

程序内部定义了四个核心函数，能够完整输出任意属性在战斗中的攻防克制链：

| 函数 | 含义 | 说明 |
|:----:|:----|:----|
| `kz`  | 克制   | 攻击方克制防御方的属性 |
| `bdk` | 被抵抗 | 攻击方被防御方抵抗的属性 |
| `bkz` | 被克制 | 攻击方被防御方克制的属性 |
| `dk`  | 抵抗   | 攻击方抵抗防御方的属性 |

### 🎯 单 / 双属性灵活计算

支持用户输入**单个属性**或**双属性组合**。在计算双属性时，程序会自动进行集合运算（交集与并集），合并两者的防御克制面，并利用 `<-` 符号特别标出双属性共同克制或共同抵抗的属性，帮助玩家直观评估双属性精灵的实际生存与输出能力。

### ⌨️ 便捷的拼音缩写识别

为提升输入效率，代码内置了强大的拼音映射字典（`w_to_z`），支持多种输入方式：

| 输入方式 | 示例 | 对应属性 |
|:--------:|:----:|:--------:|
| 属性全称 | `火`  | 火 |
| 完整拼音 | `huo` | 火 |
| 拼音首字母 | `h`  | 火 |
| 拼音首字母 | `pt` | 普通 |

### 💻 交互式命令行体验

采用 `while` 循环构建了持续运行的交互界面，玩家可在一次启动中**无限次查询**不同属性组合，直至按下 `Enter` 键主动结束程序。

## 🚀 快速开始

### 环境要求

- Python 3.x

### 运行方式

```bash
python RocoAttribute.py
```

### 使用示例

#### 单属性查询

输入单个属性即可查询其完整的克制关系：

```
请输入属性：火
正在搜索：  【火】
克  制：    草 冰 虫 机械
被抵抗：    水 地 龙
被克制：    水 地
抵  抗：    草 冰 虫 萌 机械
```

#### 双属性查询

输入两个属性（空格分隔），程序会合并计算两者的防御克制面：

```
请输入属性：火 草
正在搜索：  【火】    【草】
克  制：    草 冰 虫 机械    水 光 地
被抵抗：    水 地 龙    火 龙 毒 虫 翼 机械
被克制：    水 地 <- 龙 毒 虫 翼
抵  抗：    草 冰 虫 萌 机械    水 光 地 电
```

> 💡 ` <- ` 符号左侧为双属性**共同**克制 / 抵抗的属性，右侧为**任一**属性克制 / 抵抗的属性。
