## 📖 项目简介

本项目是一个基于《洛克王国》世界观的 Python 工具集，目前包含两个独立模块：

| 模块 | 文件 | 功能 |
|:----:|:----|:----|
| 🧮 属性克制计算器 | `RocoAttribute.py` | 计算全部 18 种属性的克制 / 抵抗关系 |
| 🥚 精灵特殊进化查询 | `RocoEvolution.py` | 查询精灵的特殊进化触发方式 |

`RocoAttribute.py` 内置了游戏内全部 18 种属性（普通、草、火、水、光、地、冰、龙、电、毒、虫、武、翼、萌、幽、恶、机械、幻）的复杂交互逻辑，可精准计算任意属性组合在战斗中的攻防克制链。

`RocoEvolution.py` 收录了需要特殊条件才能进化的精灵及其触发方式，支持多种输入格式快速查阅。

## 🧮 模块一：属性克制计算器（RocoAttribute.py）

### 🔍 多维关系查询

程序内部定义了四个核心函数，能够完整输出任意属性在战斗中的攻防克制链：

| 函数 | 含义 | 说明 |
|:----:|:----|:----|
| `kz`  | 克制   | 攻击方克制防御方的属性 |
| `bdk` | 被抵抗 | 攻击方被防御方抵抗的属性 |
| `bkz` | 被克制 | 攻击方被防御方克制的属性 |
| `dk`  | 抵抗   | 攻击方抵抗防御方的属性 |

### 🎯 单 / 双属性灵活计算

支持用户输入**单个属性**或**双属性组合**。在计算双属性时，程序会自动进行集合运算（交集与并集），合并两者的防御克制面，并利用 `<-` 符号特别标出双属性共同克制或共同抵抗的属性，帮助玩家直观评估双属性精灵的实际生存与输出能力。

### ⌨️ 便捷的拼音缩写识别

为提升输入效率，代码内置了强大的拼音映射字典（`w_to_z`），支持多种输入方式：

| 输入方式 | 示例 | 对应属性 |
|:--------:|:----:|:--------:|
| 属性全称 | `火`  | 火 |
| 完整拼音 | `huo` | 火 |
| 拼音首字母 | `h`  | 火 |
| 拼音首字母 | `pt` | 普通 |

### 💻 交互式命令行体验

采用 `while` 循环构建了持续运行的交互界面，玩家可在一次启动中**无限次查询**不同属性组合，直至按下 `Enter` 键主动结束程序。

### 使用示例

#### 单属性查询

输入单个属性即可查询其完整的克制关系：

```
请输入属性：火
正在搜索：  【火】
克  制：    草 冰 虫 机械
被抵抗：    水 地 龙
被克制：    水 地
抵  抗：    草 冰 虫 萌 机械
```

#### 双属性查询

输入两个属性（空格分隔），程序会合并计算两者的防御克制面：

```
请输入属性：火 草
正在搜索：  【火】    【草】
克  制：    草 冰 虫 机械    水 光 地
被抵抗：    水 地 龙    火 龙 毒 虫 翼 机械
被克制：    水 地 <- 龙 毒 虫 翼
抵  抗：    草 冰 虫 萌 机械    水 光 地 电
```

> 💡 ` <- ` 符号左侧为双属性**共同**克制 / 抵抗的属性，右侧为**任一**属性克制 / 抵抗的属性。

## 🥚 模块二：精灵特殊进化查询（RocoEvolution.py）

部分精灵无法通过常规升级进化，需要满足特定的触发条件。本模块收录了这些精灵的特殊进化方式，方便玩家快速查阅。

### ⌨️ 多种输入格式

与属性计算器一致，本模块同样支持多种输入格式查询同一只精灵：

| 输入方式 | 示例 | 对应精灵 |
|:--------:|:----:|:--------:|
| 三位编号 | `039` | 矿晶虫 |
| 昵称全称 | `矿晶虫` | 矿晶虫 |
| 完整拼音 | `kuangjingchong` | 矿晶虫 |
| 拼音缩写 | `kjc` | 矿晶虫 |

### 📚 已收录进化方式

| 编号 | 精灵 | 拼音缩写 | 特殊进化方式 |
|:----:|:----:|:--------:|:----|
| 039 | 矿晶虫 | `kjc` | 挖三次矿石 |
| 060 | 伏地兽 | `fds` | 32级，击败3虫 |

### 使用示例

```
查阅进化方式请输入精灵昵称(三位编号/昵称全拼/昵称缩写):kjc
挖三次矿石
```

输入错误时程序会提示重新输入，直至查询成功：

```
查阅进化方式请输入精灵昵称(三位编号/昵称全拼/昵称缩写):xxx
输入错误，请重新输入
```

## 🚀 快速开始

### 环境要求

- Python 3.x

### 运行方式

```bash
# 属性克制计算器
python RocoAttribute.py

# 精灵特殊进化查询
python RocoEvolution.py
```

两个模块均采用 `while` 循环构建持续运行的交互界面，可在一次启动中**无限次查询**，直至按下 `Enter` 键主动结束程序。
